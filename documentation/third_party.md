# Third-party code

`pipeline/build_peptide.py` and `capped/cap_build.py` contain code from other projects: PyMOL's `attach_amino_acid` routine (`pymol/modules/pymol/editor.py`) and the `build_seq` extension by Robert L. Campbell (copyright 2005; originally published on his Queen's University page and the PyMOL wiki, copy at https://github.com/zigeuner/robert_campbell_pymol_scripts). The authors of this repository modified both files for the pipeline. The original copyright headers are kept in the files and must not be removed.
